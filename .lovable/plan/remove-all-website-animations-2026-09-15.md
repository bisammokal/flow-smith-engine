# Remove all website animations

## Scope
- Remove or disable all visible animation and movement across every page.
- Preserve page content, layout, colors, navigation, and links.
- Stop entrance animations, hover movement, animated backgrounds, counters, marquees, smooth scrolling, and embedded autoplay motion where controllable.

## Implementation
- Add a global no-motion baseline covering CSS animations and transitions.
- Render motion-driven content immediately in its final visible state.
- Replace changing counters and the animated 3D background with static presentation.
- Verify the build and key pages remain visually stable.
